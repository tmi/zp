# cs05-cashme

Cashme project skeleton with Rust library, Rust CLI app, and Python wheel.

## Build and Test

Use `just` to build and test:
- `just build`: Build the Python wheel.
- `just test`: Run both Python and Rust tests.
- `just test-py`: Run Python tests.
- `just test-rs`: Run Rust tests.
- `just val`: Run all lints, type checks, and tests.
