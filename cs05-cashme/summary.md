# Summary

Implementation of a Rust library and app with a Python wheel interface using `maturin` and `pyo3`.

## Accomplishments
- Implemented Rust library with `Request` and `Response` structs and `Message` trait.
- Created a Python interface via `pyo3` wrapping Rust methods.
- Built a Rust CLI app with `clap`.
- Configured `pyproject.toml` and `uv` for Python project management.
- Integrated `just` for task automation.
- Verified functionality with both Rust and Python tests.
