# Concurrency micro-benchmark — C implementation spec

## 0. What this is (read first)

This is an **artificial concurrency micro-benchmark**, not production code, and in
C it is explicitly a **for-fun** port: we implement only the interesting
hand-rolled coordination strategies, not the standard-library queue variants
(there is no portable, idiomatic C stdlib concurrent queue worth benchmarking).

Because it is artificial:

- Do **not** add logging, config parsing frameworks, graceful shutdown, or
  abstractions. Keep it blunt. It is fine to `perror`+`exit` on setup failure.
- Do **not** exploit the CPU/allocator beyond what a competent engineer writes.
  No inline asm, no SIMD intrinsics. Do not deliberately pessimize either.
- Busy-wait (spin) is expected and preferred over sleeping. Assume enough cores
  for `P + T + 1` threads.
- Use **manual threads** (`pthread_create`), no pools.

Target: C11 with `<stdatomic.h>` and POSIX threads. Compile with
`-O2 -pthread -lm`.

## 1. Folder layout

Create a folder `c/` as a sibling of this `spec/` folder. It is **completely
self-contained** — shares nothing with the other language folders.

```
c/
  run.sh
  bench.c
```

`run.sh` (thin wrapper; build noise → stderr):

```bash
#!/usr/bin/env bash
set -euo pipefail
cd "$(dirname "$0")"
cc -O2 -std=c11 -pthread -o bench bench.c -lm 1>&2
exec ./bench
```

## 2. Parameters (all via environment variables)

| Var     | Meaning                                          | Example   |
|---------|--------------------------------------------------|-----------|
| `N`     | number of messages                               | `1000000` |
| `K`     | floats per message                               | `64`      |
| `I`     | transformer complexity (max norm order)          | `8`       |
| `P`     | producer thread count                            | `1`       |
| `T`     | transformer thread count                         | `4`       |
| `M`     | method: `B A R` only (see §6)                    | `A`       |
| `ALLOC` | `allocate` or `pool` (see §7)                    | `pool`    |
| `RING`  | ring capacity, power of two (used by `R`)        | `1024`    |
| `S`     | suite: `test` or `<warmup>/<real>`               | `3/10`    |
| `SEED`  | RNG seed (optional, default `42`)                | `42`      |

Read with `getenv`; parse with `strtoull`/`strtol`. Missing required var →
`fprintf(stderr,...)` + `exit(1)`. If `M` is anything other than `B`/`A`/`R`
(e.g. any `Q*`), print an error to stderr and exit non-zero — the queue variants
are **not** implemented in C by design.

## 3. Message, transform, and the correctness oracle

- A **message** is `float[K]`.
- The **producer** for id `i` fills it:
  - **all-ones** (`S == test`): every element `1.0f`.
  - **random** (otherwise): a cheap inline xorshift seeded from
    `SEED + producer_index` giving `[0,1)`. Do **not** use `rand()` in the hot
    loop (it is slow and not thread-safe). Keep RNG negligible vs transform.
- The **transformer** maps `const float* x -> double`:

```c
double transform(const float *x, unsigned I, int K) {
    double total = 0.0;
    for (unsigned i = 1; i <= I; i++) {
        double s = 0.0;
        for (int k = 0; k < K; k++)
            s += pow(fabs((double)x[k]), (double)i);   /* runtime exponent */
        total += pow(s, 1.0 / (double)i);
    }
    return total;
}
```

  Use `pow` with a **runtime** exponent (no special-casing of small `i`).

- The **consumer** keeps a running `double sum`.

**Oracle:** with all-ones input every message output is exactly
`v = Σ_{i=1..I} K^(1/i)`. Summing `N` bit-identical doubles is order-independent,
so **`B`, `A`, `R` must all print the same `sum`** in `test` mode.

## 4. Output format (exactly this)

Per run, one line to stdout:

```
RESULT <elapsed_ns> <sum>
```

- `<elapsed_ns>`: `long long` nanoseconds (see §8).
- `<sum>`: final `double`, printed `%.6f`.

`S == test`: run once, all-ones, single `RESULT` line.
`S == "<W>/<R>"`: `W` warmup runs, a line with exactly `---`, then `R` measured
runs; each run prints a `RESULT`. Warmup+measured use **random** input. Each run
fully independent (fresh structures/threads; `pool` preallocated fresh per run in
main before timing). Only `RESULT`/`---` on stdout; diagnostics → stderr.

## 5. Threading & timing protocol

1. Main thread does all setup (allocate arrays/rings; if `ALLOC==pool`,
   preallocate `N` buffers). **Untimed.**
2. Create+start the **consumer** (1) and **transformer** (`T`) threads; they begin
   spinning on empty input.
3. Record `start` (see §8).
4. Create+start the **producer** (`P`) threads.
5. The consumer, after consuming exactly `N` outputs, records `end` into a shared
   variable.
6. Main `pthread_join`s all threads, then prints `RESULT (end-start) sum`.

Producer `p` owns id range `[p*N/P, (p+1)*N/P)` (integer math; exact partition).

**Baseline `B`**: no threads. `start`; serial `for i in 0..N: sum +=
transform(produce(i))`; `end`; print. (`pool` preallocation still before `start`.)

Spin loop bodies should hint the CPU: use a portable helper, e.g. on x86
`__builtin_ia32_pause()`, on aarch64 `__asm__ __volatile__("yield")`, else empty
(`#ifdef` guarded). Never `usleep`/`nanosleep`.

Shared state is global or passed via a `struct*` argument to each thread. Use
`_Atomic` for shared counters/flags with explicit memory orders.

## 6. Methods

`A` and `R` share the **same termination mechanism**: one shared
`_Atomic size_t in_claim` (init 0). Each transformer:

```c
size_t idx = atomic_fetch_add_explicit(&in_claim, 1, memory_order_relaxed);
if (idx >= N) break;   /* all work claimed → exit */
/* obtain exactly one input, transform, publish exactly one output */
```

Exactly `N` items produced and `N` tickets claimed ⇒ every claiming transformer
gets exactly one item. No check-then-pop race, no loss, no deadlock.

**Cache-line-pad every contended counter.** Put each shared counter in its own
64-byte-aligned struct, e.g.:

```c
typedef struct { _Alignas(64) _Atomic size_t v; char pad[64 - sizeof(size_t)]; } counter_t;
```

### 6.A — `A`: full-size lock-free slot array

Allocate (in main, untimed) length-`N` arrays:

- `float **pbuf`  — one message pointer per id.
- `_Atomic int *pready` — flags, init 0.
- `double *cval` — outputs per id.
- `_Atomic int *cready` — flags, init 0.

**Producer** `p` (writes by id — no shared write index):

```c
for (size_t id = start; id < end; id++) {
    float *b = (ALLOC==pool) ? pbuf[id] : malloc(sizeof(float)*K);
    fill(b, id);
    if (ALLOC!=pool) pbuf[id] = b;                         /* plain store */
    atomic_store_explicit(&pready[id], 1, memory_order_release);   /* publish */
}
```

**Transformer:**

```c
for (;;) {
    size_t idx = atomic_fetch_add_explicit(&in_claim, 1, memory_order_relaxed);
    if (idx >= N) break;
    while (atomic_load_explicit(&pready[idx], memory_order_acquire) == 0) cpu_pause();
    double out = transform(pbuf[idx], I, K);
    cval[idx] = out;                                       /* plain store */
    atomic_store_explicit(&cready[idx], 1, memory_order_release);  /* publish */
}
```

**Consumer:**

```c
double sum = 0.0;
for (size_t idx = 0; idx < N; idx++) {
    while (atomic_load_explicit(&cready[idx], memory_order_acquire) == 0) cpu_pause();
    sum += cval[idx];
}
end = now_ns();
```

Correctness: the `release` store on `pready`/`cready` synchronizes-with the
`acquire` load, making the preceding plain writes (`pbuf[idx]` / `cval[idx]`)
visible. Each slot: exactly one writer, exactly one reader. Do not mark the
payload arrays `volatile` (that is not a synchronization primitive in C); the
atomic flags provide ordering.

### 6.R — `R`: Vyukov bounded MPMC ring buffer

Canonical Vyukov bounded MPMC queue. Two rings: `in_ring` (payload `float*`),
`out_ring` (payload `double`). `CAP = RING` (power of two, `mask = CAP-1`).

```c
typedef struct { _Atomic size_t seq; /* payload */ } cell_t;  /* one type per payload */
/* per ring: cell array; cell[j].seq initialized to j;
   counter_t enqpos, deqpos both 0 (cache-line padded, see §6). */

int enqueue(ring *r, PAYLOAD item) {
    size_t pos = atomic_load_explicit(&r->enqpos.v, memory_order_relaxed);
    for (;;) {
        cell_t *c = &r->cells[pos & r->mask];
        size_t seq = atomic_load_explicit(&c->seq, memory_order_acquire);
        intptr_t dif = (intptr_t)seq - (intptr_t)pos;
        if (dif == 0) {
            if (atomic_compare_exchange_weak_explicit(&r->enqpos.v, &pos, pos+1,
                    memory_order_relaxed, memory_order_relaxed)) {
                c->payload = item;
                atomic_store_explicit(&c->seq, pos+1, memory_order_release);
                return 1;
            }
        } else if (dif < 0) return 0;   /* full */
        else pos = atomic_load_explicit(&r->enqpos.v, memory_order_relaxed);
    }
}

int dequeue(ring *r, PAYLOAD *out) {
    size_t pos = atomic_load_explicit(&r->deqpos.v, memory_order_relaxed);
    for (;;) {
        cell_t *c = &r->cells[pos & r->mask];
        size_t seq = atomic_load_explicit(&c->seq, memory_order_acquire);
        intptr_t dif = (intptr_t)seq - (intptr_t)(pos+1);
        if (dif == 0) {
            if (atomic_compare_exchange_weak_explicit(&r->deqpos.v, &pos, pos+1,
                    memory_order_relaxed, memory_order_relaxed)) {
                *out = c->payload;
                atomic_store_explicit(&c->seq, pos + r->mask + 1, memory_order_release);
                return 1;
            }
        } else if (dif < 0) return 0;   /* empty */
        else pos = atomic_load_explicit(&r->deqpos.v, memory_order_relaxed);
    }
}
```

- **Producer:** `while (!enqueue(in_ring, b)) cpu_pause();`
- **Transformer:** claim ticket; if `< N`, spin-`dequeue` a `float*` from
  `in_ring`, transform, spin-`enqueue` the `double` to `out_ring`.
- **Consumer:** loop `N` times, spin-`dequeue` a `double` from `out_ring`, add.

## 7. Allocation modes (`ALLOC`)

- **`allocate`**: producers `malloc` each `float[K]` inside the timed region.
- **`pool`**: main thread, before `start`, allocates all `N` buffers (one big block
  or `N` small ones) and stores them into `pbuf[id]` (for `A`) or a `float**
  pool` indexed by id (for `R`). Producers fill `pool[id]`/`pbuf[id]` in place and
  pass the pointer on. No `malloc` in the timed region.

Buffers may leak at process exit; do not bother freeing (this is a benchmark that
exits after each process run). The harness runs one process per configuration.

## 8. Timing details

Use `clock_gettime(CLOCK_MONOTONIC, ...)` converted to `long long` nanoseconds:

```c
static long long now_ns(void){ struct timespec t; clock_gettime(CLOCK_MONOTONIC,&t);
    return (long long)t.tv_sec*1000000000LL + t.tv_nsec; }
```

`start` in main immediately before creating producer threads; `end` in the
consumer immediately after the `N`-th output. Report `end - start`. Producer
thread-creation cost is intentionally inside the measured region. No warmup logic
beyond the `S` warmup runs.

## 9. Harness interface

The outer harness sets env vars and calls `c/run.sh` once per configuration.
`run.sh` emits only `RESULT`/`---` on stdout and exits non-zero on error.

## 10. Implementation checklist (avoid these bugs)

- [ ] `in_claim` via `atomic_fetch_add`; transformers stop at `idx >= N`. No
      check-then-pop pattern.
- [ ] Every contended counter is 64-byte aligned/padded (`enqpos`, `deqpos`,
      `in_claim`).
- [ ] Payload published via `release` store / `acquire` load; one writer + one
      reader per `A` slot. Payload arrays are not `volatile`.
- [ ] Vyukov `seq` init `= j`; dequeue release stores `pos + CAP`. `RING` is a
      power of two.
- [ ] Spin loops call `cpu_pause()`; no `usleep`/`nanosleep`.
- [ ] `pool` preallocation before `start`; `M ∈ {B,A,R}` else refuse.
- [ ] `test` mode: single run, all-ones, `B`/`A`/`R` print identical `sum`.
- [ ] Consumer captures `end`; main prints `RESULT (end-start) sum` with `%.6f`.
