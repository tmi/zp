# Simple Dungeon Game

A retro-style dungeon crawling game for kids.

## Setup

Use `uv` to manage dependencies.

```bash
uv sync
```

## Running the game

```bash
uv run python main.py
```

## Features

- Retro ASCII graphics using `curses`.
- Multiple levels with increasing complexity.
- Random placement of treasures and traps.
- Easy-to-edit level files and asset strings.
- Pleasant, kid-friendly vibrant colors.

## Controls

- **Arrows**: Move your avatar (P)
- **R**: Restart current level
- **Q**: Quit game
- **N**: Back to Main Menu
